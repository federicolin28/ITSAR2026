# Lezione 01 – Kickoff: Unity, Git e vibe coding

## Punto di partenza (`lezione-01-inizio`)

- Progetto Unity 6 (Universal 3D) ripulito dai contenuti del template
- Struttura delle cartelle in `Assets/_Project`
- Scena `Arena` con il terreno, una luce, la camera e il **cristallo** al centro
- `.gitignore` per Unity

## Laboratorio

Obiettivo: generare con l'AI il primo script, leggerlo, testarlo e committarlo.

1. Fai un commit dello stato iniziale (o crea un tuo branch dal tag).
2. Chiedi all'AI lo script `Rotator`.
3. Leggi il codice e spiegalo a voce, riga per riga.
4. Aggiungi lo script al cristallo e premi Play.
5. Chiedi all'AI di rendere configurabile anche l'asse di rotazione.
6. Controlla il diff in GitHub Desktop e fai commit.

### Prompt di esempio

> Sto usando Unity 6 LTS con URP. Scrivi un MonoBehaviour chiamato Rotator che ruota il
> GameObject attorno all'asse Y. La velocità, in gradi al secondo, deve essere configurabile
> da Inspector con [SerializeField]. Il movimento deve essere indipendente dal framerate.
> Poi spiegami il codice riga per riga.

### Criteri di accettazione

- Il cristallo ruota alla stessa velocità indipendentemente dagli FPS
- Velocità e asse si modificano dall'Inspector
- I campi sono `private` con `[SerializeField]`, non `public`

## Soluzione (`lezione-01-fine`)

`Assets/_Project/Scripts/Core/Rotator.cs`, assegnato al cristallo.
